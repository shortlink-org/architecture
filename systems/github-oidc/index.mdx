## Overview

GitHub is configured as an OIDC provider in Kratos with the `user:email` scope. Claims are mapped onto identity
traits through `oidc.github.jsonnet`.

Sign-in through this provider skips email verification — the registration `oidc` path runs the `session` hook only.
