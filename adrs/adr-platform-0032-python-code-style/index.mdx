## Context

The Python code style tool needed standardising, weighing efficiency and developer experience.

## Decision

Adopt [Ruff](https://docs.astral.sh/ruff/) over Flake8, on the strength of its speed.

## Consequences

A faster review loop. The shortest ADR in the set, and a good example of the format's value at small scale — the
choice takes one line, but the record of *why* Flake8 was displaced is what stops the question being reopened.
