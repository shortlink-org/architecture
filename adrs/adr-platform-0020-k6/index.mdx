## Context

Integration tests are needed to verify correctness beyond the unit level.

## Decision

Use [k6](https://k6.io/), built with the distributed tracing extension:

```bash
go install go.k6.io/xk6/cmd/xk6@latest
xk6 build --with github.com/grafana/xk6-distributed-tracing@latest
```

## Consequences

Tests emit traces into the same system as production traffic, so a failing integration test can be inspected in
Tempo rather than only through its assertion output.

The [[domain|Link]] boundary carries k6 suites for exactly this —
`ops/link/draft/test/e2e/k6_rpc_cqrs_link_v1.yaml` and `k6_rpc_sitemap_v1.yaml` exercise the CQRS and sitemap RPC
surfaces.
