## Context

The user interface needs protection against spam and automated data extraction.

## Decision

Use [Cloudflare Turnstile](https://developers.cloudflare.com/turnstile/) — a CAPTCHA alternative that can be embedded
without routing traffic through Cloudflare and that usually verifies a visitor without showing them a challenge.

In the UI, the [React Turnstile](https://docs.page/marsidev/react-turnstile/) component.

## Consequences

Protection against automated abuse with, in most cases, no visible step for the user — the ADR is explicit that
where a challenge does appear, the extra friction is accepted deliberately.
