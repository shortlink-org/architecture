## Context

Service health needs to be monitorable and metrics collectable in one standard way across the platform.

## Decision

Three HTTP endpoints on **port 9090** in every service:

| Endpoint | Returns |
|----------|---------|
| `/metrics` | Prometheus-formatted metrics |
| `/healthz` | JSON with `status`: `ok` or `error` |
| `/ready` | JSON with `status`: `ok` or `error` |

A Docker `HEALTHCHECK` calls `/healthz`, and Kubernetes probes are generated from a shared Helm template:

```gotemplate
{{- include "shortlink-common.probe" .Values.deploy | indent 6 }}
```

## Consequences

This is the decision that lets every service's `AuthorizationPolicy` carve out the same paths. The Istio policies
in the [[domain|Auth]] boundary allow `/live`, `/ready`, `/healthz` and `/metrics` without a JWT precisely because
they are guaranteed to mean the same thing everywhere.
