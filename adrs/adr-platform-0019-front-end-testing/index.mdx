## Context

A growing application needs a reliable front-end testing strategy, and a consistent way to test APIs.

## Decision

- [Cypress](https://www.cypress.io/) with
  [Cypress Testing Library](https://testing-library.com/docs/cypress-testing-library/intro/) for the front end
- Postman for manual API testing, Newman for the same collections in CI

## Consequences

Issues are caught earlier, at the cost of maintaining a browser-driven suite.

> [!NOTE]
> The UI boundary in the monorepo now carries a `playwright-report/` directory, which suggests the front-end tooling
> has moved on from Cypress without this ADR being updated. Treat the Cypress half as historical until confirmed.
