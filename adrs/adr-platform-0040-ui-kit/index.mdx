## Context

The React projects need a unified UI approach for consistency and faster development.

## Decision

Build a UI kit of the essential components, with Storybook for interactive development and testing. Referenced
libraries for component coverage: [Sailboat UI](https://sailboatui.com/),
[Pines](https://devdojo.com/pines), [Float UI](https://floatui.com/demo).

## Consequences

The kit is published and consumed across the front ends — the [[domain|Auth]] UI depends on
`@shortlink-org/ui-kit`, which is what keeps the Kratos self-service screens looking like the rest of the product
despite living in a different repository.
