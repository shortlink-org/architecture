## Context

Logging needs one standard shape across all services.

## Decision

JSON, with this field set:

```json
{
  "level": "info",
  "msg": "message",
  "timestamp": "2006-01-02T15:04:05.999999999Z07:00",
  "caller": "main.go:42",
  "trace_id": "trace_id"
}
```

Application logs are recorded as [span events](https://uptrace.dev/opentelemetry/distributed-tracing.html#event)
named `log`, with the context carried in semantic attributes:

- `level` — one of `DEBUG`, `INFO`, `WARN`, `ERROR`, `FATAL`
- `msg`, `timestamp` (RFC3339Nano), `caller`, `trace_id` (hex-encoded)

## Consequences

Logs are not a separate stream to correlate after the fact — they hang off the trace. `trace_id` in every line is
what makes a log searchable from a Tempo trace and back again.
