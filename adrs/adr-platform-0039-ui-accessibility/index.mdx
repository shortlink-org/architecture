## Context

The UI needs to be accessible to people with disabilities.

## Decision

Honour the browser's accessibility media queries, beginning with
[`prefers-reduced-transparency`](https://developer.chrome.com/blog/css-prefers-reduced-transparency/) for visual
impairments:

```css
.bg-white {
  @media (prefers-reduced-transparency: reduce) {
    --tw-bg-opacity: 0;
  }
}
```

## Consequences

Accessibility is treated as a system preference to respond to rather than a setting to build — the browser already
knows what the user needs, and the UI's job is not to override it.
