## Context

Product metrics need to be visible per service, not only in aggregate.

## Decision

Build a Grafana dashboard of product metrics for each service.

## Consequences

The dashboard covers four non-functional groups:

| Group | Metrics |
|-------|---------|
| Production | RPS / TPS / latency |
| Persistence | SLA / RTO / RPO |
| Security | PCI DSS, internal, external |
| Compliance | GDPR, ФЗ‑152, KYC-AML |

Compliance sits alongside latency in the same dashboard requirement, which makes it an operational property rather
than a document reviewed once.
