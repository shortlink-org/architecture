## Overview

Published by [[service|CourierEmulationService]], consumed by [[service|DeliveryService]], which advances the
[[entity|Package]] to `IN_TRANSIT` and emits [[event|PackageInTransit]].

## Delivery

| | |
|---|---|
| Topic | [[channel\|delivery.order.order_picked_up.v1]] |
| Serialization | JSON |
| Consumer | [[service\|DeliveryService]] |
| Wired by | `KAFKA_PICKUP_TOPIC` |

The topic is named for what the receiver does with it rather than for a package lifecycle transition — these are
inbound topics from the delivery service's point of view, and its Strimzi configuration declares them as such.
