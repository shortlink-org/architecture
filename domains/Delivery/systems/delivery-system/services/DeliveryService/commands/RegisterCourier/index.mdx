## Overview

`DeliveryService.RegisterCourier`. Creates a [[entity|Courier]] with contact details, transport type, maximum
distance, work zone, work hours and a push token for assignment notifications.

## Contract

```proto
rpc RegisterCourier(RegisterCourierRequest) returns (RegisterCourierResponse);
```

## Capacity is not an input

`max_load` is derived from `transport_type` rather than supplied — the same rule
[[command|ChangeCourierTransportType]] re-applies later.

## Effect

Emits [[event|CourierRegistered]]. The push token is deliberately not on the event.
