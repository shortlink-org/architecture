## Overview

`DeliveryService.DeliverOrder`. One command for both terminal outcomes, distinguished by the status field:

```proto
message DeliverOrderCommand {
  string package_id = 1;
  string courier_id = 2;
  DeliveryStatus status = 3;   // DELIVERED or NOT_DELIVERED
  string reason = 4;           // required when NOT_DELIVERED
  bytes photo = 5;             // optional
  bytes customer_signature = 6;// optional
  Location current_location = 7;
}
```

## Effect

Emits [[event|PackageDelivered]] or [[event|PackageNotDelivered]] depending on `status`.

The courier's location after the attempt is captured either way, so a failed delivery still records where the
courier was when it failed.
