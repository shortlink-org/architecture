## Overview

`DeliveryService.UpdateContactInfo`.

The phone matters beyond contact detail: it is copied onto [[event|PackageAssigned]] so the customer side can reach
the courier for an in-flight delivery.

## Effect

No dedicated event — profile changes do not appear on [[channel|delivery.courier.events.v1]], which carries only
registration and status transitions.
