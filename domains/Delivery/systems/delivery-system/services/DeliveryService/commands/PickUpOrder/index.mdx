## Overview

`DeliveryService.PickUpOrder`. Moves a [[entity|Package]] from `ASSIGNED` to `IN_TRANSIT`.

## Contract

```proto
rpc PickUpOrder(PickUpOrderRequest) returns (PickUpOrderResponse);
```

## Usually driven by Kafka, not by this RPC

In practice the courier side confirms pickup by publishing [[event|OrderPickedUp]] to
[[channel|delivery.order.order_picked_up.v1]], which the service consumes. The RPC exists for direct callers.

## Effect

Emits [[event|PackageInTransit]].
