## Overview

`DeliveryService.GetRandomAddress`. Returns one address within a bounding box supplied by server configuration —
Berlin by default, matching the OSRM extract.

## Contract

```proto
// GetRandomAddressRequest is empty; bounds come from server config (env)
message GetRandomAddressRequest {}

message GetRandomAddressResponse {
  Address address = 1;
}
```

## It is test scaffolding on a production API

Nothing in the delivery domain needs a random address. It exists to seed demos and to give
[[service|CourierEmulationService]] plausible destinations inside the routable region.

Worth knowing it is there: it is reachable on the same gRPC service as every real operation, and it is the one RPC
whose behaviour depends on nothing but configuration.
