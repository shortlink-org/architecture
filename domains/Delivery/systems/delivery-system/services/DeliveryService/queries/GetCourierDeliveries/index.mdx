## Overview

`DeliveryService.GetCourierDeliveries`. Delivery history for one [[entity|Courier]].

## Contract

```proto
rpc GetCourierDeliveries(GetCourierDeliveriesRequest) returns (GetCourierDeliveriesResponse);
```

The aggregate itself carries `successful_deliveries` and `failed_deliveries` counters; this query returns the
individual records behind them.
