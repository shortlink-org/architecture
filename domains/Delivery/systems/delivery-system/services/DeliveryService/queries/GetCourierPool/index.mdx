## Overview

`DeliveryService.GetCourierPool`. The working view over the fleet — filtered, paginated and sorted.

## Contract

```proto
message GetCourierPoolQuery {
  repeated CourierStatus status_filter = 1;
  repeated TransportType transport_type_filter = 2;
  string zone_filter = 3;
  bool available_only = 4;      // FREE couriers only
  bool include_location = 5;
  Pagination pagination = 6;
  SortBy sort_by = 7;
}
```

## Location is opt-in

`include_location` exists because the current position does not live in Postgres — it is a TTL'd key in
[[container|delivery-redis]]. Asking for it turns one query into a query plus a cache fan-out, so it is a flag
rather than a default.

A courier that has stopped reporting comes back with no location at all.

## Sorting

`SORT_BY_DISTANCE` requires courier location and is therefore only meaningful with `include_location` set. The
remaining options — name, rating, load, successful deliveries — are plain column sorts.

Page size is capped at 100.
