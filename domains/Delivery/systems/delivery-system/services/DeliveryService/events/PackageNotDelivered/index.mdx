## Overview

Terminal failure for an attempt. Carries the courier's location and `NotDeliveredDetails` — an enum plus a
description that is required only when the reason is `OTHER`:

`CUSTOMER_NOT_AVAILABLE`, `WRONG_ADDRESS`, `CUSTOMER_REFUSED`, `ACCESS_DENIED`, `PACKAGE_DAMAGED`, `OTHER`.

## Structured on purpose

An earlier schema stored a free-text `not_delivered_reason` column; migration
`m20260316_000009_drop_legacy_not_delivered_reason` removed it. Downstream systems can now route on the reason
without parsing prose, and the distinction survives the translation into [[event|OrderDeliveryFailed]].
