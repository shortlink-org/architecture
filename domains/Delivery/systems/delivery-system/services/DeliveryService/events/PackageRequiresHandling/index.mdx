## Overview

The escape hatch of the package state machine: something is wrong and no automatic transition applies. Carries a
free-text `reason`.

## Nobody acts on it

[[service|OMSService]] consumes the status topic but explicitly rejects this message as a non-status event — its
handler recognises only `ACCEPTED`, `ASSIGNED`, `IN_TRANSIT`, `DELIVERED` and `NOT_DELIVERED`, returning
`errUnsupportedEventType` for anything else.

So a package can end up in `REQUIRES_HANDLING` and the order will show its last known delivery status indefinitely.
There is no operator surface for it either — [[service|SupportService]], which would be the natural home, is a
skeleton.
