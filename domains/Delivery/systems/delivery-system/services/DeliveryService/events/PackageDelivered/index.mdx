## Overview

Terminal success for a [[entity|Package]]. Carries the delivery location, the time, and optionally a confirmation
photo and a customer signature as raw `bytes`.

[[service|OMSService]] turns this into [[event|OrderDeliveryCompleted]].

## Delivery

| | |
|---|---|
| Topic | [[channel\|delivery.package.status.v1]] |
| Key | `package_id` |
| Consumer | [[service\|OMSService]] |

> [!NOTE]
> The photo and signature fields make this the heaviest message on the topic. They are optional, but a consumer
> sizing its fetch limits should not assume a package event is small.
