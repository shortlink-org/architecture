## Overview

Produced by [[service|LinkService]], consumed by [[service|MetadataService]] to trigger enrichment.

On Kafka this is a topic; on RabbitMQ the chart provisions a durable fanout exchange of the same name
(`ops/link/templates/rabbitmq/exchange/link.link.created.v1.yaml`), gated on `MQ_TYPE: rabbitmq`. Production runs
Kafka.
