## Overview

Produced by [[service|LinkService]], consumed by [[service|MetadataService]] to trigger enrichment.

On Kafka this is a topic; on RabbitMQ the chart provisions a durable fanout exchange of the same name
(`ops/link/templates/rabbitmq/exchange/link.link.created.v1.yaml`), gated on `MQ_TYPE: rabbitmq`. Production runs
Kafka.

<NodeGraph />

## Provisioning

Declared as a Strimzi `KafkaTopic` in the `kafka` namespace by the chart of the service that publishes it:

| | |
|---|---|
| Partitions | 1 |
| Replicas | 3 |
| Retention | **2 hours** (`retention.ms: 7200000`) |
| Segment size | 30MB |

> [!NOTE]
> Retention is two hours, so this channel is a transport rather than a log. Consumers are expected to be online;
> there is no history to replay from and no catch-up beyond that window.
