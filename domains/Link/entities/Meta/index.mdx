## Keyed by URL

`id` is the URL, not the hash. That is the join key used when folding metadata into
[[container|link-cqrs-readmodel]], and it means metadata is a property of a *target page*, not of a link: two links
pointing at the same URL describe the same `Meta`.

The flip side is that a link whose URL changes through [[event|LinkUpdated]] does not automatically re-enrich —
nothing re-triggers extraction for the new target.
