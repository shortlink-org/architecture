## Overview

A properly encapsulated aggregate: every field is unexported and reachable only through getters, and instances are
produced by a builder rather than constructed literally. `GetAllowedEmails` returns a copy, so a caller cannot mutate
the allowlist through the slice it receives.

## The hash

Six characters from a 62-symbol alphabet (`a-z`, `A-Z`, `0-9`) — about **56.8 billion** combinations, against an
estimated 5M links a day. [[adr|adr-link-0004-domain-link]] works the numbers.

The hash is derived from URL + salt, which has a consequence worth stating: it is not an opaque surrogate key. Change
the URL and the hash of a *new* link for that URL changes too, but the existing link keeps its address.

## Public and private

Privacy is derived from the allowlist rather than stored as a flag:

```go
func (m *Link) IsPublic() bool {
	if m == nil {
		return true
	}

	return len(m.allowedEmails) == 0
}
```

Emails are normalised before comparison, and the allowlist is validated by a chain of specifications — format,
duplicates, non-empty entries, and a maximum size.

### How this relates to SpiceDB

A link is governed by two mechanisms, and they are split **by operation** rather than duplicated —
[[adr|adr-platform-0042-link-privacy-control]] is the decision that draws the line:

| Operation | Enforced by |
|-----------|-------------|
| GET / redirect | this allowlist, with the caller's email fetched from the Kratos Admin API |
| List, Create, Update, Delete, team RBAC | SpiceDB relations |

The SpiceDB side is [[adr|adr-auth-0003-access-control-schema]]. It is deliberately **not** consulted on the
redirect path. A public link is returned without calling either
Kratos or SpiceDB at all.

## Not on the aggregate

`Meta` is deliberately absent. Title, description, keywords and image belong to [[entity|Meta]], are produced by a
different service, and are joined in only on the read side as [[entity|LinkView]].
