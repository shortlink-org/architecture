## Overview

The BFF is the only part of the domain a browser talks to. It terminates the REST API at
`https://shortlink.best/api`, and calls [[service|LinkService]] over gRPC behind it.

It is also the service the Zero Trust path in [[domain|Auth]] ends at: Oathkeeper's `api:bff-protected` rule
forwards `https://shortlink.best/api/<**>` here with a JWT, and the pod's Istio `AuthorizationPolicy` rejects
anything that arrives without one.

## The route to Oathkeeper lives here

The `HTTPRoute` that sends `https://shortlink.best/api` to `oathkeeper-proxy.auth:4455` is part of **this service's**
chart, not the Oathkeeper chart. The service being protected declares how it is protected, and the `auth` namespace
permits the cross-namespace reference with a `ReferenceGrant`.

The Envoy rate limit is local to each sidecar rather than a shared quota, so the effective platform limit is 200/s
multiplied by the replica count. Throttled responses carry `x-rate-limited: true`.

See [[system|istio-edge]] for the full routing table and the policies attached to this workload.
