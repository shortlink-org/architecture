## Overview

The BFF is the only part of the domain a browser talks to. It terminates the REST API at
`https://shortlink.best/api`, and calls [[service|LinkService]] over gRPC behind it.

It is also the service the Zero Trust path in [[domain|Auth]] ends at: Oathkeeper's `api:bff-protected` rule
forwards `https://shortlink.best/api/<**>` here with a JWT, and the pod's Istio `AuthorizationPolicy` rejects
anything that arrives without one.

## API

Built with `chi` and generated from the OpenAPI document by `oapi-codegen`. It covers link and sitemap operations
with `limit`/`cursor` pagination.

> [!NOTE]
> In the repository the spec is split across five files (`api.yaml`, `base.yaml`, `link.yaml`, `sitemap.yaml`,
> `config.yaml`) that reference each other with relative `$ref`s. The copy in this catalog is a **bundled**
> single-file version — the catalog's OpenAPI renderer resolves only the document it is given and silently fails on
> cross-file references. Regenerate it with `npx @redocly/cli bundle api.yaml -o api.yaml --ext yaml` when the
> upstream spec changes.
