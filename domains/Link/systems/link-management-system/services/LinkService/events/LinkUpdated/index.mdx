## Overview

Emitted by [[service|LinkService]] after a link's URL or description changes. The payload carries the state *after*
the change — there is no before/after pair and no field mask on the event, so a consumer that needs to know what
changed must diff against its own copy.

The hash is derived from URL + salt, so changing the URL of an existing link changes what it points to while keeping
the same short address. That is the case this event exists to broadcast — caches keyed by hash (notably the
[[container|proxy-redis-cache]]) hold data that is now wrong.
