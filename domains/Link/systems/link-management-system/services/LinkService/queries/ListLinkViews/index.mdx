## Overview

`LinkQueryService.List` takes a filter string and returns a `LinksView`.

## Contract

```proto
message ListRequest {
  // Filter is the filter to apply to the Links.
  string filter = 1;
}

message ListResponse {
  // Links is the LinksView for the given filter.
  LinksView links = 1;
}
```

> [!NOTE]
> The read-side `List` takes a filter but no pagination — unlike the CRUD `LinkService.List`, which has `limit` and
> `cursor`. The two list operations in this service are not interchangeable.
