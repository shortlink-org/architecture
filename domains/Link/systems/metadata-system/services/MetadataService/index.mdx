## Overview

The metadata service exists so that creating a link stays fast. Parsing a remote page is slow and can fail; doing it
inline would put an arbitrary third-party website on the critical path of "shorten this URL". Instead the work hangs
off [[event|LinkCreated]] and the result comes back as [[event|MetadataExtracted]].

## Coupling

This service subscribes to another service's event type: it imports `linkpb.LinkCreated` and registers it in its own
CQRS registry.

```go
// LinkCreated - metadata service processes new links to extract metadata
err := registry.RegisterEvent(&linkpb.LinkCreated{})
```

That is a deliberate shared contract, not an accident — but it means the protobuf definition of `LinkCreated` is a
published interface of [[service|LinkService]], and changing it is a cross-service change.
