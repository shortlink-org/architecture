## Overview

Produced by [[service|OMSService]] carrying [[event|CartReset]]. No consumer today.

A reset is emitted both when a customer clears their cart and when checkout consumes it, so this event alone does
not tell a consumer which happened — [[event|OrderCreated]] is what distinguishes the two.

## The name is not what the code says it is

> [!WARNING]
> `domain/cart/v1/event.proto` claims `oms.cart.reset.v1` and `ResetEvent.EventType()` returns `Reset`. Neither is
> the topic. The bus names events through `namer.EventName(evt)`, and because `ResetEvent` is a plain Go struct
> rather than a protobuf message the namer falls back to the service name as the aggregate — giving `oms.oms.` and
> keeping the Go type name, `Event` suffix included.

See [[channel|oms.oms.item_added_event.v1]] for the full comparison.
