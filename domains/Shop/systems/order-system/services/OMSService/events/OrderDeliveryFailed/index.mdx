## Overview

Derived from [[event|PackageNotDelivered]]. Carries the courier id, the failure time and `NotDeliveredDetails`.

> [!WARNING]
> The protobuf comment on this message says it is "received from delivery service". It is not. This event is
> **published by** [[service|OMSService]] from `usecases/order/event/on_delivery_status/handler.go`, after it
> consumes a package status change off [[channel|delivery.package.status.v1]] and applies it to the
> [[entity|Order]].

## The reason survives the translation

`NotDeliveredDetails` is an enum plus an optional description, and the description is required only when the
reason is `OTHER`:

`CUSTOMER_NOT_AVAILABLE`, `WRONG_ADDRESS`, `CUSTOMER_REFUSED`, `ACCESS_DENIED`, `PACKAGE_DAMAGED`, `OTHER`.

A consumer can therefore route on the reason without parsing prose — an address problem and an absent customer need
different follow-up.
