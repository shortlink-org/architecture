## Overview

The event that turns a purchase into a platform-wide fact. It carries order id, customer id, the full item list,
status and both `created_at` and `occurred_at` — so a consumer can act without calling back into
[[service|OMSService]].

## Delivery

| | |
|---|---|
| Topic | [[channel\|oms.order.created.v1]] |
| Broker | Kafka, via the Postgres outbox forwarder |
| Serialization | JSON, from the protobuf-defined shape |
| Consumers | none inside the boundary |

One of the three Shop events whose topic actually matches
[[adr|adr-platform-0002-canonical-event-naming]].

## Aggregate version

`aggregate_version` rides along on every order event. It is what lets consumers reject a redelivered or
out-of-order message — the leaderboard consumer keys its idempotency marker on it.
