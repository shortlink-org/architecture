## Overview

Derived from [[event|PackageDelivered]]. Carries the courier id, the delivery time and the delivery location.

> [!WARNING]
> The protobuf comment on this message says it is "received from delivery service". It is not. This event is
> **published by** [[service|OMSService]] from `usecases/order/event/on_delivery_status/handler.go`, after it
> consumes a package status change off [[channel|delivery.package.status.v1]] and applies it to the
> [[entity|Order]].

## Delivery

> [!NOTE]
> This is not [[event|OrderCompleted]]. Delivery completing and the order reaching its terminal state are separate
> transitions on separate state machines — only the latter feeds the leaderboard.
