## Overview

Published when an order with delivery information is sent to [[domain|Delivery]]. It carries the pickup and
delivery addresses, the delivery period, package info and priority, plus the `package_id` once it is known.

> [!WARNING]
> **This event does not request anything.** The actual request is a synchronous gRPC [[command|AcceptOrder]] call
> made from a Temporal activity in [[service|OMSService]], which is also where the `package_id` comes from.
> [[service|DeliveryService]] does not subscribe to this or any other `oms.*` topic.
>
> The event exists so that observers can see delivery was requested. A consumer written against it as a trigger
> will never fire.
