## Overview

`OrderService.Checkout` on [[service|OMSService]] — the main path a customer takes, and the start of the
[[flow|Checkout]] flow.

## Contract

```proto
rpc Checkout(CheckoutRequest) returns (CheckoutResponse);
```

The only order command that returns a response body rather than `Empty`, because the caller needs the resulting
order.

## What it does

Reads the [[entity|Cart]], prices it through [[query|CalculateCartTotal]], creates the [[entity|Order]], and
empties the cart.

If the order carries delivery information, the order workflow then runs the `RequestDelivery` activity — a
synchronous gRPC [[command|AcceptOrder]] into [[domain|Delivery]].

## Effects

Emits [[event|OrderCreated]] and [[event|CartReset]]; [[event|OrderDeliveryRequested]] follows when the order
ships.
