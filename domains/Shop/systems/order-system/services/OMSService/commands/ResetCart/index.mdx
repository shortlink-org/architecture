## Overview

`CartService.Reset` on [[service|OMSService]] — the RESET signal on the [[entity|Cart]] workflow.

## Contract

```proto
rpc Reset(ResetRequest) returns (google.protobuf.Empty);
```

## Effect

Emits [[event|CartReset]]. The same event is emitted when checkout consumes a cart, so consumers cannot tell the
two apart from this event alone.
