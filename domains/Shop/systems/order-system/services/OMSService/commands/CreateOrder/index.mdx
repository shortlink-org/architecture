## Overview

`OrderService.Create` on [[service|OMSService]]. Drives the CREATE transition, moving the [[entity|Order]] from
`PENDING` to `PROCESSING`.

## Contract

```proto
rpc Create(CreateRequest) returns (google.protobuf.Empty);
```

## Not the same as checkout

This creates an order from an explicit item list. [[command|CheckoutOrder]] creates one from an existing
[[entity|Cart]] and returns the result. Both exist; they are alternative entry points, not layers.

## Effect

Emits [[event|OrderCreated]].
