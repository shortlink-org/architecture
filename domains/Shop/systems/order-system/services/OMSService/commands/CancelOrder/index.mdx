## Overview

`OrderService.Cancel` on [[service|OMSService]] — the CANCEL transition, reachable from both `PENDING` and
`PROCESSING`.

## Contract

```proto
rpc Cancel(CancelRequest) returns (google.protobuf.Empty);
```

## Effect

Emits [[event|OrderCancelled]] carrying the reason when one was supplied.

> [!NOTE]
> Cancelling an order does not cancel its package. [[domain|Delivery]] exposes no cancel operation on
> [[service|DeliveryService]] at all — an order cancelled after [[command|AcceptOrder]] leaves a live
> [[entity|Package]] behind.
