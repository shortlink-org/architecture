## Overview

`CartService.Add` on [[service|OMSService]]. Signals the ADD transition on the [[entity|Cart]] workflow.

## Contract

```proto
service CartService {
  rpc Add(AddRequest) returns (google.protobuf.Empty);
}
```

Returns `Empty` — the caller gets no cart back. Reading the cart is a separate [[query|GetCart]] call.

## No create step

The handler loads the cart by `customer_id` and constructs an empty one in place if none exists, so a client never
has to create a cart before filling it.

## Effect

Emits [[event|CartItemAdded]], written to the outbox in the same transaction as the aggregate save.
