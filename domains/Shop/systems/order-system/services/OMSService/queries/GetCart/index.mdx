## Overview

`CartService.Get` on [[service|OMSService]] — the only read on the cart service.

## Contract

```proto
rpc Get(GetRequest) returns (GetResponse);
```

## No price

The response carries items and quantities, not a total. Pricing is a separate call to
[[query|CalculateCartTotal]], deliberately — a cart never stores a price, so it can never show a stale one.
