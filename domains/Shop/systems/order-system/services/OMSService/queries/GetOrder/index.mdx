## Overview

`OrderService.Get` on [[service|OMSService]].

## Contract

```proto
rpc Get(GetRequest) returns (GetResponse);
```

Reads from [[container|oms-postgres]] — the same store the aggregate is written to. There is no CQRS read model for
orders, unlike the [[domain|Link]] domain.

## Delivery information

An order that ships carries `package_id` and `delivery_status`, both updated by consuming
[[channel|delivery.package.status.v1]]. Live tracking is not here — that is
[[query|GetOrderTracking]] in the [[domain|Delivery]] boundary, keyed by this same order id.
