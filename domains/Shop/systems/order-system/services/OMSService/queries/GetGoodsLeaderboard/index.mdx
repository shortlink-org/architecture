## Overview

`OrderService.GetLeaderboard` on [[service|OMSService]].

## Contract

```proto
rpc GetLeaderboard(GetLeaderboardRequest) returns (GetLeaderboardResponse);
```

## Not a query over orders

This does not aggregate the `orders` table. It reads Redis sorted sets in
[[container|oms-redis-leaderboard]], built by consuming [[event|OrderCompleted]] off Kafka.

That makes the answer eventually consistent: an order completed a second ago may not be ranked yet. It also makes
it cheap, and rebuildable from the event log.

See [[adr|adr-shop-0006-goods-leaderboard-read-model]].

## Windows

Day, week and month sets are maintained separately, with retentions of 45, 400 and 800 days.
