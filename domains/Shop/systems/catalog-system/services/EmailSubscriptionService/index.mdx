## Intent

Per its README: a Temporal workflow in Go that notifies subscribers when new goods appear, modelled on Temporal's
own `email-subscription-project-go` sample. The single use case is "notify about new goods".

## What would have to exist first

There is no event to subscribe to. [[service|AdminService]] publishes nothing when a [[entity|Good]] is created —
the catalogue keeps its history in database tables, not in Kafka. A working implementation would need a goods
event on the publishing side before the subscription side has anything to react to.

> [!NOTE]
> The repository's root README lists this service as "Python (Django)". The directory contains a `go.mod`. The
> README inside the service says Temporal and Go, which is what this page follows.
