## Overview

A typed adapter and nothing else. It sits between [[service|ShopBFF]] on port 4012 and
[[service|AdminService]] on port 8000, turning federated GraphQL requests into Django REST calls.

```text
Cosmo Router → admin-graphql (Go/Connect) → Django Admin API
    :9991            :4012                        :8000
```

## What it exposes

**Goods.** That is the whole surface today — [[entity|Office]] is not in the graph.

## Why it exists

The catalogue speaks REST because it is Django; everything else in the domain speaks GraphQL or gRPC. Rather than
teach the router to federate a REST service, the translation is a service of its own with a generated, typed
contract (`pkg/graph/schema.graphql`, `pkg/proto/service/v1/service.proto`, generated with `buf`).

## No state of its own

No database, no cache, no events. If it is down, goods disappear from the graph; nothing is lost.
