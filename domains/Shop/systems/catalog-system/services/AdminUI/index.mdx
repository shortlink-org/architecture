## Overview

The interface a back-office user works in. It talks to [[service|ShopBFF]], not to [[service|AdminService]]
directly — so the back office and the storefront read the catalogue through the same graph.

## Stack

Next.js with generated GraphQL types (`codegen.ts`, `graphql/`), Tailwind, and Vitest for tests.

> [!NOTE]
> This service has no README in the repository — only a `ROADMAP.md`. What is documented here is read from
> `package.json`, `codegen.ts` and the directory layout rather than from prose.

## Not the Django admin

Django's own admin interface still exists inside [[service|AdminService]]. This is a separate front end over the
federated graph; the two are not the same surface and can disagree about what is editable.
