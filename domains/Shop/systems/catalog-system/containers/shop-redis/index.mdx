## What is this?

Ordinary Django caching for [[service|AdminService]], at `redis://redis-master.shortlink-shop:6379/0`.

Nothing authoritative lives here and nothing else reads it. It is listed because the deployment depends on it: the
service will not start without it in the default configuration.

> [!NOTE]
> The migration path deliberately bypasses it. `settings_migration.py` runs with a minimal app set and no Redis, so
> that a schema migration does not require the cache to be up.
