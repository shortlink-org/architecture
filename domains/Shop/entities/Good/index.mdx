## Two names that are not this one

| Name | Where | What it actually is |
|------|-------|---------------------|
| `Product` | [[service\|ShopUI]] TypeScript types | the same thing, named for the Shopify-shaped GraphQL the storefront was forked from |
| `Item` | retired Merch service | an SKU-level inventory unit — a different level of abstraction, not a synonym |

## Price is not a number

`price` is a `MoneyField`: an amount **and** a currency, with two decimal places. Pricing calculations preserve that
precision by passing decimals as strings across the wire — see [[query|CalculateCartTotal]], where every monetary
field in the contract is a `string`.

## History without events

The model uses `simple_history`, so every change appends to a historical table. The catalogue therefore has a full
audit trail while publishing no events at all — a cart or order references a good by id and re-reads it when needed.

> [!NOTE]
> [[event|StockChange]] would have been the exception. It is declared in the order engine's protobuf and
> implemented nowhere.
