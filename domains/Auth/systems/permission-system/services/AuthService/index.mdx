## What it actually does

On startup the permission service walks its embedded `permissions/` directory, unmarshals every `.yaml` file into
a `WriteSchemaRequest` and applies it to SpiceDB:

```go
//go:embed permissions/*
var permissions embed.FS

func New(ctx context.Context, log logger.Logger, permissionClient *authzed.Client) (*Service, error) {
	svc := &Service{permission: permissionClient}

	if err := svc.Migrations(ctx, permissions); err != nil {
		return nil, err
	}

	log.Info("Permission migrations completed")
	// ...
}
```

The schema file (`internal/services/permission/permissions/auth.zed.yaml`) carries its own assertions and
validation blocks, so the authorization model is testable in isolation — see
[[system|permission-system]] for the schema itself.
