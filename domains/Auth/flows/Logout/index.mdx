## Revocation is not instant everywhere

The session dies immediately, and every *new* request is rejected at the edge. But a JWT minted moments before
logout is a signed bearer token with a 15-minute TTL and no introspection step behind it — an internal service
holding one cannot tell that the session behind it is gone.

## Where it is triggered from is not documented

[[service|AuthUI]] serves `/login`, `/registration`, `/forgot` and `/verification`; there is no logout page in that
route table. The use case is real — the [[service|AuthService]] README lists *UC-2 Log out*, and
[[service|Kratos]]' self-service state machine has the logout edge — but which surface calls it is not recorded in
this catalog.
