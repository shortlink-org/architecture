## Where visitors come from

Most sign-ins do not start on this page. An unauthenticated HTML request through the edge is answered by
[[service|Oathkeeper]] with a `302` to `https://shortlink.best/auth/login` — the first branch of
[[flow|AuthenticatedRequest]].

## The UI holds no logic

[[service|AuthUI]] asks Kratos for the flow and renders whatever nodes come back. Password, GitHub and GitLab are
all the same code path in the browser; which methods exist is decided by Kratos configuration.

## What the visitor leaves with

A session cookie, and nothing else. No token is issued here — the 15-minute RS256 JWT that internal services see is
minted per request at the edge, from this session.
