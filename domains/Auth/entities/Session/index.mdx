## Overview

A Session is created by [[service|Kratos]] on successful login or registration and returned as the
`ory_kratos_session` cookie.

## Cookie

| Attribute | Value |
|-----------|-------|
| Name | `ory_kratos_session` |
| Domain | `shortlink.best` |
| SameSite | `Lax` |
| Lifespan | `720h` (30 days) |

## Scope

The cookie never enters the cluster. [[service|Oathkeeper]] is the last component that sees it; everything behind
the proxy works from an [[entity|AccessToken]] instead. This is why the session lifespan (30 days) and the token
TTL (15 minutes) are so far apart — they protect different things.

## AAL

`aal2` is reached with TOTP or a lookup secret. The settings flow requires `highest_available`, so a user who has
configured 2FA must re-satisfy it before changing their profile or password. The login flow additionally has a
`10m` lifespan — the flow itself expires, independently of the session it creates.
