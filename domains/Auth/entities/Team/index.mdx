## Overview

Team exists only in [[container|spicedb]]; there is no team table in [[container|kratos-postgres]] and no team
concept in the identity schema. It is a purely relational object.

## Definition

```
definition team {
    relation administrator: user
    relation member: user

    permission view_all_links = administrator
}
```

## How a team grants access

Two mechanisms, and they behave differently:

1. **As a subject set** — `link:x#reader@team:t#member` grants read to whoever is a member *at check time*. Adding
   a member grants access to every link shared this way, with no per-link write.
2. **Through ownership** — `link:x#linkteam@team:t` plus `permission view = ... + linkteam->view_all_links` lets
   team administrators view the link. Members get nothing from this path; administrators get it on every link the
   team owns.

Neither path grants `edit`, which is `writer` and nothing else.
